Python Expense Tracker
Project Description

Python Expense Tracker is a console-based application developed using Python to record, manage, and track daily expenses.

The application allows users to add expenses, view all expense records, calculate total spending, generate category-wise summaries, and search expenses by category.

All expense records are stored permanently using CSV file handling.

Features
Add new expenses with date, category, description, and amount.
View all recorded expenses.
Calculate total expenses.
Generate category-wise expense summaries.
Search expenses by category.
Store expense records in a CSV file.
Handle invalid user inputs using exception handling.

How to Run the Project
Step 1: Install Python

Download and install Python 3 from:

https://www.python.org/downloads/

Step 2: Clone the Repository
bash
git clone YOUR_GITHUB_REPOSITORY_URL

Step 3: Open the Project Folder

Open the downloaded project folder in Visual Studio Code.

Step 4: Run the Application

Open the VS Code terminal and execute:

bash
py expense_tracker.py
